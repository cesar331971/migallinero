# Mi Gallinero

Aplicación web instalable para Windows/macOS/Linux y Android. Los gastos se guardan en el propio dispositivo, incluso sin conexión.

## Abrir e instalar

1. Publica esta carpeta en un alojamiento web HTTPS (por ejemplo, GitHub Pages, Netlify o Cloudflare Pages), o ábrela mediante un servidor web local; los navegadores no habilitan la instalación desde un archivo `file://`.
2. En Windows, abre la URL con Edge o Chrome y pulsa **Instalar app** cuando aparezca.
3. En Android, ábrela con Chrome, usa el menú ⋮ y elige **Instalar aplicación** o **Añadir a pantalla de inicio**.

## Incluye

- Registro y borrado de gastos.
- Totales mensuales, acumulados y kilos de pienso.
- Gráfica mensual sin dependencias externas.
- Exportación de todos los datos a CSV.
- Uso sin conexión tras la primera visita.

Los datos permanecen en el navegador del dispositivo. Para llevarlos a otro teléfono u ordenador, usa **Exportar CSV**.
